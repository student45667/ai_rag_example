## Answer

To create an Arduino IDE code for ESP32 that handles Bluetooth TX/RX messages and connects to a PC over serial, you can use the `BluetoothSerial` library. This library allows you to redirect serial communication to Bluetooth, enabling data exchange between the ESP32 and a PC.

Here's a basic example of how you can set up an ESP32 with Bluetooth for serial communication:

```cpp
#include <BluetoothSerial.h>

#if !defined(CONFIG_BT_ENABLED) || !defined(CONFIG_BLUEDROID_ENABLED)
#error Bluetooth is not enabled! Please run `make menuconfig` to and enable it
#endif

BluetoothSerial SerialBT;

void setup() {
  // Initialize serial for debugging
  Serial.begin(115200);
  
  // Initialize Bluetooth
  SerialBT.begin("ESP32_BT"); // Rename your device here
  
  Serial.println("The device started, now you can pair it with bluetooth!");
}

void loop() {
  if (Serial.available()) {
    String data = Serial.readString();
    SerialBT.write(data); // Send data via Bluetooth
  }
  
  if (SerialBT.available()) {
    String data = SerialBT.readString();
    Serial.println(data); // Print received data to the Serial monitor
  }
}
```

### Explanation:

1. **Include Library**: The `BluetoothSerial` library is included at the beginning of the code.
2. **Check Bluetooth Configuration**: The code checks if Bluetooth is enabled in the project settings (`make menuconfig`). If not, it will not compile.
3. **Initialize Serial and Bluetooth**:
   - `Serial.begin(115200);` initializes the serial communication for debugging purposes at 115200 baud rate.
   - `SerialBT.begin("ESP32_BT");` starts the Bluetooth connection with a name "ESP32_BT".
4. **Loop Function**:
   - The code reads data from the serial port (`Serial`) and sends it over Bluetooth using `SerialBT.write(data);`.
   - It also listens for incoming data on the Bluetooth connection and prints it to the Serial monitor.

### Steps to Use:

1. Open the Arduino IDE.
2. Create a new sketch.
3. Copy and paste the above code into the sketch.
4. Replace `"ESP32_BT"` with a name of your choice for the ESP32 in the Bluetooth connection.
5. Connect the ESP32 to your PC using a USB cable.
6. Upload the sketch to the ESP32.
7. Open the Serial Monitor in the Arduino IDE and set the baud rate to 115200.
8. Pair your PC with the ESP32 using the Bluetooth device name you specified in the code.

With this setup, any data sent from the serial monitor on your PC will be forwarded to the ESP32 via Bluetooth, and any data received by the ESP32 will appear in the Serial Monitor on your PC.
