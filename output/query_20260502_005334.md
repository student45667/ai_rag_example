## Answer

To connect an ADXL362 I2C accelerometer to your ESP32 and display the X, Y, and Z axis data on an OLED screen using an SSD1306 display, you will need to use several libraries:

- `Wire.h` for I2C communication.
- `Adafruit_GFX.h` and `Adafruit_SSD1306.h` for handling the OLED display.
- `Adafruit_ADXL345_U.h` for interfacing with the ADXL362 accelerometer.

Here's a step-by-step guide to set up your project:

### Required Libraries:
- `Wire.h`
- `Adafruit_GFX.h`
- `Adafruit_SSD1306.h`
- `Adafruit_ADXL345_U.h`

### Example Code:

```cpp
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <Adafruit_ADXL345_U.h>

// Define the I2C address of the SSD1306 display and ADXL362 accelerometer
#define SCREEN_WIDTH 128 // OLED display width, in pixels
#define SCREEN_HEIGHT 64 // OLED display height, in pixels

// Declaration for an SSD1306 display connected to I2C (SDA, SCL pins)
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

Adafruit_ADXL345_Unified accel = Adafruit_ADXL345_Unified(12345);

void setup() {
  // Initialize serial for debugging
  Serial.begin(115200);
  
  // Initialize the OLED display
  if(!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) { // Address 0x3C for 128x64
    Serial.println(F("SSD1306 allocation failed"));
    for(;;);
  }
  delay(2000); // Pause for 2 seconds
  
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0,0);
  display.println("ADXL362 Data:");
  display.display();

  // Initialize the ADXL362 accelerometer
  if (!accel.begin()) {
    Serial.println("Failed to find ADXL362 sensor");
    while (1) delay(1);
  }
}

void loop() {
  sensors_event_t event;
  
  // Get a new sensor event 
  accel.getEvent(&event);

  if (event.acceleration.status & ACCEL_STATUS_VALID_DATA) {
    display.clearDisplay();
    display.setTextSize(1);
    display.setTextColor(SSD1306_WHITE);
    display.setCursor(0,0);
    display.println("ADXL362 Data:");
    display.print("X: ");
    display.print(event.acceleration.x);
    display.println(" m/s^2");
    display.print("Y: ");
    display.print(event.acceleration.y);
    display.println(" m/s^2");
    display.print("Z: ");
    display.print(event.acceleration.z);
    display.println(" m/s^2");
    display.display();
  } else {
    Serial.println("Error reading acceleration data");
  }

  delay(100); // Delay between readings
}
```

### Explanation:

1. **Include Libraries**: The required libraries are included at the beginning of the code.
2. **Initialize OLED Display**:
   - The SSD1306 display is initialized using the I2C address `0x3C`.
   - A message is displayed on the OLED to indicate that it is ready.
3. **Initialize ADXL362 Accelerometer**:
   - The ADXL362 accelerometer is initialized.
   - If initialization fails, an error message is printed and the loop stops.
4. **Loop Function**:
   - The code reads acceleration data from the ADXL362.
   - If valid data is received, it is displayed on the OLED screen.
   - The display is cleared and updated with each new reading.

### Steps to Use:

1. Open the Arduino IDE.
2. Create a new sketch.
3. Copy and paste the above code into the sketch.
4. Connect the ADXL362 accelerometer and SSD1306 OLED display to your ESP32 according to their respective datasheets.
5. Upload the sketch to the ESP32.
6. Open the Serial Monitor in the Arduino IDE and set the baud rate to 115200.

With this setup, you should be able to see the X, Y, and Z axis data from the ADXL362 accelerometer displayed on the OLED screen connected to your ESP32.
