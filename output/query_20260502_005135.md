## Answer

To connect an OLED display (SSD1306) over I2C and display incoming Bluetooth messages on it, you can use the `Wire` library for I2C communication and the `BluetoothSerial` library for handling Bluetooth messages. Below is a basic example of how you can set up an ESP32 with an SSD1306 OLED display to display incoming Bluetooth messages.

### Required Libraries:
- `Wire.h`: For I2C communication.
- `Adafruit_GFX.h`: Base class for graphics libraries.
- `Adafruit_SSD1306.h`: Library for the SSD1306 OLED display.
- `BluetoothSerial.h`: Library for handling Bluetooth messages.

### Example Code:

```cpp
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <BluetoothSerial.h>

// Define the I2C address of the SSD1306 display
#define SCREEN_WIDTH 128 // OLED display width, in pixels
#define SCREEN_HEIGHT 64 // OLED display height, in pixels

// Declaration for an SSD1306 display connected to I2C (SDA, SCL pins)
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

#if !defined(CONFIG_BT_ENABLED) || !defined(CONFIG_BLUEDROID_ENABLED)
#error Bluetooth is not enabled! Please run `make menuconfig` and enable it
#endif

BluetoothSerial SerialBT;

void setup() {
  // Initialize serial for debugging
  Serial.begin(115200);
  
  // Initialize Bluetooth
  SerialBT.begin("ESP32_BT"); // Rename your device here
  
  Serial.println("The device started, now you can pair it with bluetooth!");
  
  // Initialize the OLED display
  if(!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) { // Address 0x3C for 128x64
    Serial.println(F("SSD1306 allocation failed"));
    for(;;);
  }
  delay(2000); // Pause for 2 seconds
  
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0,0);
  display.println("Bluetooth Messages:");
  display.display();
}

void loop() {
  if (SerialBT.available()) {
    String data = SerialBT.readString();
    display.clearDisplay();
    display.setTextSize(1);
    display.setTextColor(SSD1306_WHITE);
    display.setCursor(0,0);
    display.println("Bluetooth Messages:");
    display.println(data);
    display.display();
  }
}
```

### Explanation:

1. **Include Libraries**: The required libraries are included at the beginning of the code.
2. **Check Bluetooth Configuration**: The code checks if Bluetooth is enabled in the project settings (`make menuconfig`). If not, it will not compile.
3. **Initialize Serial and Bluetooth**:
   - `Serial.begin(115200);` initializes the serial communication for debugging purposes at 115200 baud rate.
   - `SerialBT.begin("ESP32_BT");` starts the Bluetooth connection with a name "ESP32_BT".
4. **Initialize OLED Display**:
   - The SSD1306 display is initialized using the I2C address `0x3C`.
   - A message is displayed on the OLED to indicate that it is ready.
5. **Loop Function**:
   - The code reads data from the Bluetooth connection (`SerialBT`) and displays it on the OLED.
   - The display is cleared and updated with each new message.

### Steps to Use:

1. Open the Arduino IDE.
2. Create a new sketch.
3. Copy and paste the above code into the sketch.
4. Replace `"ESP32_BT"` with a name of your choice for the ESP32 in the Bluetooth connection.
5. Connect the ESP32 to your PC using a USB cable.
6. Upload the sketch to the ESP32.
7. Open the Serial Monitor in the Arduino IDE and set the baud rate to 115200.
8. Pair your PC with the ESP32 using the Bluetooth device name you specified in the code.

With this setup, any data sent from a paired device via Bluetooth will be displayed on the OLED display connected to the ESP32.
